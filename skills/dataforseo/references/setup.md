# DataForSEO — Setup

Run the plugin setup script:

```bash
bash ${CLAUDE_PLUGIN_ROOT}/scripts/setup.sh
```

Or use the `/fetch-ads-data-setup` command.

## Credentials

DataForSEO uses HTTP Basic auth with your **API login and API password** — shown at
https://app.dataforseo.com/api-access. The API password is generated by DataForSEO and is
not your dashboard sign-in password. The account needs a prepaid balance.

Provide them either way (environment variables win if both are set):

**Environment variables**
```bash
export DATAFORSEO_LOGIN="you@example.com"
export DATAFORSEO_PASSWORD="your-api-password"
```
The MCP server passes its environment to the scripts, so set these where your MCP host
launches the server (shell profile, or the `env` block of an MCP config).

**Credential file** — `~/.fetch-ads-data/dataforseo.json`
```json
{
  "login": "you@example.com",
  "password": "your-api-password"
}
```
The setup script drops a template here if the file doesn't exist and no env vars are set.

## Config

Optional settings in `~/.fetch-ads-data/config.json`:

```json
{
  "dataforseo": {
    "credentials": "~/.fetch-ads-data/dataforseo.json",
    "daily_cap_usd": 1.0,
    "default_location_code": 2840,
    "default_language_code": "en"
  }
}
```

- `daily_cap_usd` — daily spend cap (UTC day). Default `1.0`. Env override: `DATAFORSEO_DAILY_CAP_USD`. `0` blocks all billed calls.
- `default_location_code` / `default_language_code` — used when a call doesn't pass them. Default `2840` (United States) / `en`.
- `cost_log_dir` — where daily tallies are written. Default `~/.fetch-ads-data/dataforseo-costs/`. Env override: `DATAFORSEO_COST_LOG_DIR`.
- `pricing` — override the per-unit rates used for *projections* if DataForSEO changes prices:
  ```json
  "pricing": {
    "search_volume_live_per_task": 0.09,
    "serp_standard_per_page": 0.0006,
    "serp_priority_per_page": 0.0012,
    "serp_live_per_page": 0.002
  }
  ```
  Current rates: https://dataforseo.com/pricing

## How the spend cap works

1. Before each billed request, the projected cost is added to today's recorded total. If the
   sum exceeds the cap, the call is refused (exit code 2) and nothing is sent.
2. After each billed request, the actual `cost` from the API response is appended to
   `~/.fetch-ads-data/dataforseo-costs/YYYY-MM-DD.json`.
3. Multi-request runs (e.g. 2,000 keywords = 3 volume requests) check and record per request,
   so a run that fails midway still leaves an accurate tally.

The tally only counts calls made through this plugin on this machine, and it isn't locked
against concurrent runs — treat it as a guard rail. Set a balance alert or spending limit in
the DataForSEO dashboard for a hard limit.

`--dry-run` shows projected cost and whether it fits under the cap without spending anything.

## Verifying

```bash
~/.fetch-ads-data/venv/bin/python ${CLAUDE_PLUGIN_ROOT}/scripts/dataforseo/verify.py
```

Free call. Prints the login, account balance, and today's spend vs the cap. A `401` means
the login/password pair is wrong — use the API password from the API access page.
